## 핵심 요약 (3줄)

1. **전기**: `nvidia-smi -pl 280` 전력제한(손실 1% 미만) + 컴퓨터마다 전용 회선.
2. **구성**: vLLM 텐서 병렬은 GPU 2/4/8장 단위. 2080Ti는 vLLM에 섞지 말고 Whisper/RAG 전용.
3. **운영**: 두 대는 묶지 말고 역할 분담(A=두뇌, B=보조) 후 LiteLLM으로 주소 하나로 통합.
