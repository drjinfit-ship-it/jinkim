# 0단계. 전체 그림 — 우리가 만들 것

> 김진 박사님의 두 대의 GPU 컴퓨터로 "로컬 LLM 자동화 시스템"을 만드는 전체 지도입니다.
> 아래 1~7단계 문서를 순서대로 따라가면 됩니다.

## 지금 가진 것 (2026년 7월 기준)

| | A컴퓨터 (메인) | B컴퓨터 (서버) |
|---|---|---|
| 메인보드 | ASUS Pro WS WRX80E-SAGE SE WIFI | ASRock Rack ROMED8-2T |
| CPU | Threadripper Pro 3975WX | EPYC 7542 |
| GPU 현재 | RTX 3090 24GB × 8장 (목표 10장) | RTX 3090 × 3장 + 개조 2080 Ti 22GB × 2장 |
| GPU 목표 | 3090 × 10장 = 240GB | 3090 × 7장 + 2080 Ti × 2장 = 212GB |
| RAM | ECC 128GB | ECC 128GB |

두 보드 모두 PCIe 4.0 x16 슬롯이 **7개씩** 있고, 전부 CPU 직결이라 멀티 GPU에 최적인 보드입니다.

## 최종 목표 구조 (역할 분담 방식)

두 대를 억지로 하나로 묶는 것보다, **각자 잘하는 일을 맡기고 주소 하나로 합치는 것**이
훨씬 빠르고 안정적입니다. (근거는 `05-두-대-연동.md` 참고)

```
[갤럭시워치/Rokid 글래스/폰/맥미니/태블릿]
        │  (와이파이/인터넷)
        ▼
┌─────────────────────────────┐
│  관문 서버: LiteLLM + Open WebUI │  ← 주소 하나로 전부 접속
└──────────┬──────────────────┘
           │
   ┌───────┴────────┐
   ▼                ▼
A컴퓨터 (8×3090)      B컴퓨터 (7×3090 + 2×2080Ti)
"두뇌 담당"           "보조 담당"
- 큰 모델 1개         - 중간 모델 (문서/코딩용)
  (예: 235B급 MoE)    - Whisper 음성→글자 변환
                      - 임베딩/리랭커 (RAG 검색용)
                      - 비전 모델 (문서 사진 읽기)
```

- 2080 Ti 2장은 vLLM(주력 엔진)과 궁합이 나쁘므로 **Whisper·임베딩 전용**으로 씁니다. 이게 가장 좋은 활용법입니다.
- 정말 거대한 모델(300GB급)을 돌리고 싶을 때만 두 대를 묶습니다(5단계에서 방법 설명).

## 딱 3가지만 기억하세요

1. **전기 먼저**: 8×3090은 전력제한 없이는 벽에서 3.4kW를 뽑습니다. 반드시 `nvidia-smi -pl 280`으로 제한(성능 손실 1% 미만)하고, 컴퓨터마다 전용 콘센트 회선을 씁니다.
2. **GPU 개수는 2/4/8이 좋다**: 주력 엔진 vLLM의 텐서 병렬은 2, 4, 8장 단위로만 잘 돌아갑니다. 7장이면 실제로는 4장만 쓰게 되는 경우가 많습니다. A컴퓨터가 8장인 것은 아주 좋은 구성입니다.
3. **섞지 말 것**: 3090과 2080 Ti를 한 vLLM에 넣으면 안 됩니다. 2080 Ti는 별도 서비스(Whisper 등)로 분리합니다.
