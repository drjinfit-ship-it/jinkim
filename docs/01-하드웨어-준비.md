# 1단계. 하드웨어 준비 — 전기 → 전원 → 장착 → BIOS

> 순서가 중요합니다. **전기 → 파워(PSU) → GPU 장착 → BIOS 설정** 순서로 하세요.

## 1-1. 전기부터 확인 (제일 중요!)

### 얼마나 먹는가

- RTX 3090 1장 = 기본 350W. 8장이면 GPU만 2,800W + 본체 300~400W = **벽에서 약 3.4kW**.
- 하지만 2단계에서 배울 "전력 제한 280W"를 걸면 **8장 기준 약 2.6~2.7kW**로 줄고, 속도 손실은 1% 미만입니다. (실측 자료: Puget Systems, Jean Brito 벤치마크 — 7단계 자료 모음 참고)

### 한국 220V 가정 기준

- 콘센트 회선 1개(차단기 20A) = 이론상 4.4kW지만, **계속 쓰는 부하는 70~80%인 약 3.0~3.5kW까지만** 안전합니다.
- 멀티탭은 대부분 16A(3,520W)가 한계입니다. → **컴퓨터 1대가 멀티탭 1개를 거의 다 씁니다.**

### 해야 할 일 (순서대로)

1. 집/사무실 분전반을 열고 차단기 용량(16A/20A/30A)을 확인한다.
2. **A컴퓨터와 B컴퓨터를 서로 다른 회선(다른 차단기)에 꽂는다.** 같은 회선에 두 대를 꽂으면 차단기가 내려갑니다.
3. 24시간 돌릴 계획이면 전기기사를 불러 **전용 30A 회선 2개** 증설을 추천합니다.
4. 두 대 합쳐 24시간 가동 시 월 2,000kWh를 넘길 수 있습니다. 주택용 누진세 폭탄이 나오므로, 사업장이라면 **일반용(비주거) 계약 또는 계약전력 증설**을 한전에 문의하세요.

## 1-2. 파워(PSU) 구성

한 대의 파워로 3090 8장은 불가능합니다. 두 가지 방법 중 하나를 고릅니다.

### 방법 A: ATX 파워 2~3개 연결 (쉬움)

1. 1600W급 파워 2개를 준비한다. (전력제한 280W 기준, 1000W당 3090 약 3장)
2. "add2psu" 보드(1~2만원)로 두 파워가 같이 켜지게 연결한다.
3. **규칙 1**: GPU 1장마다 파워에서 나오는 **별도의 8핀 케이블 2개**를 쓴다. 한 케이블에서 갈라지는 문어발(데이지체인)은 금지.
4. **규칙 2**: 한 GPU의 전원 케이블과 그 GPU가 꽂힌 라이저의 보조전원은 **반드시 같은 파워**에서 나와야 한다. (다른 파워에서 나눠 받으면 고장 위험)
5. 메인보드 24핀·CPU 전원은 1번 파워가 담당한다.

### 방법 B: 서버 파워 + 브레이크아웃 보드 (채굴장 방식, 220V에 최적)

- HP 1200W 플래티넘 서버파워(중고 저렴)는 **220V에서만 1200W 풀출력**이 나옵니다. 한국 환경에 딱 맞습니다.
- Parallel Miner X11 같은 브레이크아웃 보드에 꽂아 8핀 케이블을 뽑아 씁니다. 파워 여러 개 연동 기능도 있습니다.

### WRX80E-SAGE 전용 주의사항

보드 위에 **추가 6핀 PCIe 보조전원 커넥터가 2개** 있습니다. GPU를 많이 꽂을 때 슬롯 전력 안정화를 위한 것이니 **둘 다 꼭 꽂으세요.**

## 1-3. GPU 장착과 라이저

3090은 2~3슬롯 두께라 보드에 7장을 직접 꽂을 수 없습니다. → **오픈 프레임(채굴 프레임) + 라이저 케이블**이 정답입니다.

### 라이저 고르기 (중요)

| 종류 | 속도 | 용도 |
|---|---|---|
| PCIe 4.0 리본 라이저 (LINKUP 등, 25cm 이하) | x16 | 기본 선택. 싸구려는 금물 |
| SlimSAS(SFF-8654) 어댑터 (C-Payne 등) | x8×2 | 슬롯 1개→GPU 2장. 신호 가장 깨끗함. 확장 시 최선 |
| OCuLink 어댑터 | x4 | **B컴퓨터(ROMED8-2T)는 보드에 OCuLink 포트가 2개 내장** → GPU 2장 추가 가능 |
| M.2 → PCIe x4 어댑터 (ADT-Link F43SG 등) | x4 | M.2 슬롯으로 GPU 추가. 예비용 |

### "x16인데 x1로만 인식돼요" 문제 (현재 겪고 계신 것)

PCIe 4.0은 신호가 예민해서 라이저가 조금만 불량이어도 x16→x8→x4→**x1**로 뚝뚝 떨어집니다. 해결 순서:

1. 라이저를 뺐다가 다시 꽉 꽂는다 (접촉 불량이 1위 원인).
2. 그래도 안 되면 **BIOS에서 그 슬롯만 PCIe Gen3으로 강제**한다. Gen3은 신호 여유가 커서 거의 항상 풀 대역폭이 살아납니다. Gen3 x16(16GB/s)도 LLM에는 충분합니다.
3. 그래도 안 되면 라이저를 Gen4 인증 제품(LINKUP Ultra, ADT-Link) 25cm 이하로 교체한다.

확인 명령(우분투): `nvidia-smi --query-gpu=index,pcie.link.gen.current,pcie.link.width.current --format=csv`

### 대역폭은 얼마나 필요한가

- **vLLM 텐서 병렬(속도 중시)**: GPU당 x8 이상 권장. x4면 5~10% 손해.
- **llama.cpp 레이어 분할(용량 중시)**: x4, 심지어 x1도 동작함(모델 로딩만 느려짐).
- 결론: 주력 GPU는 x8~x16으로, OCuLink/M.2로 붙인 GPU는 llama.cpp용이나 보조용으로.

### 냉각

1. 오픈 프레임에서 GPU 사이를 한 뼘 이상 띄운다.
2. 3090의 약점은 **뒷면 VRAM**(GDDR6X, 95°C 스로틀링). 중고 카드는 **서멀패드 교체**(Fujipoly 등 고성능 패드)로 VRAM 온도가 최대 25°C 내려갑니다.
3. 전력제한 280W가 최고의 냉각 대책입니다.
4. 카드 뒷판(백플레이트)에 작은 팬을 붙이면 몇 도 더 내려갑니다.

## 1-4. B컴퓨터(ROMED8-2T) BIOS 설정

> 모니터 없이도 됩니다! 이 보드는 **IPMI 원격관리**가 내장돼 있습니다.
> 전용 IPMI 랜포트에 케이블을 꽂고, 다른 컴퓨터 브라우저에서 IPMI 주소로 접속하면
> 화면·키보드·전원버튼·BIOS까지 전부 원격으로 됩니다. GPU 서버 운영의 필수 기능입니다.

부팅하며 `F2` 또는 `Del` (원격이면 IPMI의 iKVM 화면에서):

1. `Advanced → PCI Configuration → Above 4G Decoding` = **Enabled** (GPU 4장 이상이면 필수)
2. `Advanced → AMD CBS → NBIO` 에서 `MMIO High Base` / `MMIO High Granularity Size` = **512G 이상** (GPU 6장 이상에서 부팅 실패 방지)
3. 라이저 문제 있는 슬롯: 해당 슬롯 Link Speed = **Gen3**
4. `CSM` = **Disabled**
5. IOMMU/SVM = **Disabled** (가상머신 안 쓸 때. GPU끼리 직접 통신에 유리)
6. **PCIE2 슬롯 점퍼 주의**: 이 보드의 PCIE2 슬롯은 M.2_1, SATA4~7, OCuLink와 레인을 공유합니다. 보드의 PE8_SEL/PE16_SEL 점퍼로 선택:
   - 기본값: PCIE2 = x16, M.2_1 꺼짐
   - 점퍼 변경: PCIE2 = x8 + M.2_1 켜짐 ← **M.2 SSD를 쓰면서 GPU도 꽂으려면 이 설정**
   - 다른 조합: PCIE2 끄고 OCuLink 2개 켜기 (매뉴얼 2.6절 점퍼표 참고)

## 1-5. A컴퓨터(WRX80E-SAGE) BIOS 설정

부팅하며 `Del`:

1. `Advanced → PCI Subsystem Settings → Above 4G Decoding` = **Enabled**
2. `Resizable BAR` = 일단 **Disabled** (부팅 문제 예방. 나중에 P2P 패치 쓸 때만 켬)
3. 라이저 슬롯 Gen3 강제 (필요 시)
4. 10장 확장 시: 슬롯별 **PCIe Bifurcation(x8/x8 분할)** 메뉴 사용 → 슬롯 1개에 SlimSAS 어댑터로 GPU 2장. 이 보드는 실사용자가 12장까지 성공한 기록이 있습니다(14장은 실패). 10장 목표는 검증된 범위입니다.
5. BIOS를 최신으로 업데이트 (분할 메뉴가 최신 BIOS에서 확장됨)
