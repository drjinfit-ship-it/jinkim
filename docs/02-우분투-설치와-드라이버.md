# 2단계. 우분투 설치와 엔비디아 드라이버

> B컴퓨터(ROMED8-2T)는 이미 우분투입니다. 이 문서 순서대로 점검만 하면 됩니다.
> A컴퓨터(WRX80E)는 현재 윈도우인데, **우분투로 바꾸는 것을 강력 추천**합니다.
> 이유: 윈도우(WDDM 드라이버)는 GPU 간 전송이 느리고, 멀티GPU P2P 최적화가 불가능합니다.
> 리눅스 대비 멀티GPU 성능이 크게 떨어집니다. 윈도우가 필요하면 SSD를 하나 더 달아 듀얼부팅하세요.

## 2-1. 우분투 서버 24.04 LTS 설치

1. 다른 컴퓨터에서 https://ubuntu.com/download/server 에서 24.04 LTS ISO를 받는다.
2. Rufus(윈도우) 또는 balenaEtcher로 USB에 굽는다.
3. USB를 꽂고 부팅 → 부팅 메뉴(F11/F8)에서 USB 선택.
4. 설치 중 선택:
   - 언어: English (서버는 영어가 문제 해결에 유리)
   - "Install OpenSSH server" **체크** (원격 접속 필수)
   - 나머지는 기본값
5. 설치 후 재부팅 → 같은 공유기에 연결된 다른 컴퓨터에서 접속:
   ```bash
   ssh 사용자이름@서버IP주소
   ```
   (IP는 서버에서 `ip addr` 명령으로 확인)

## 2-2. 엔비디아 드라이버 설치 (2026년 기준: 580 브랜치)

서버에 SSH로 접속한 뒤, 아래를 한 줄씩 복사해 실행합니다.

```bash
# 1) 시스템 최신화
sudo apt update && sudo apt upgrade -y

# 2) 추천 드라이버 확인
sudo ubuntu-drivers devices
# → "recommended"라고 표시된 것 확인 (예: nvidia-driver-580)

# 3) 서버용(화면 출력 없는) 드라이버 설치
sudo apt install -y nvidia-headless-580 nvidia-utils-580

# 4) 재부팅
sudo reboot
```

재부팅 후 확인:

```bash
nvidia-smi
```

→ GPU가 **전부**(예: 8개) 목록에 나오면 성공. 개수가 모자라면 1단계의 라이저/BIOS 항목을 다시 점검하세요.

> 참고: 나중에 "P2P 패치"(GPU끼리 직접 통신, 성능 +10~30%)를 쓰려면
> `nvidia-headless-580-open`(오픈 커널 모듈)을 설치해야 합니다. 처음엔 일반 버전으로 시작해도 됩니다.

## 2-3. 필수 설정 3가지

```bash
# 1) 퍼시스턴스 모드 (GPU 상태 유지, 반응속도/유휴전력 개선)
sudo systemctl enable --now nvidia-persistenced

# 2) 그래픽 화면 끄기 (VRAM과 전기 절약 — 서버는 필요 없음)
sudo systemctl set-default multi-user.target

# 3) 전력 제한 280W (성능 손실 1% 미만, 전기 20% 절약, 발열 대폭 감소)
sudo nvidia-smi -pm 1
sudo nvidia-smi -pl 280
```

### 전력 제한 실측 근거 (RTX 3090, LLM 추론)

| 전력 제한 | 속도 손실 | 비고 |
|---|---|---|
| 350W (기본) | 0% | 8장 = 벽에서 ~3.4kW |
| **280W** | **약 1%** | **추천값**. 8장 = ~2.6kW |
| 250W | 약 3% | 전기 아끼고 싶으면 |
| 200W | **-35%** | 절벽. 여기까지 내리지 말 것 |

LLM 생성 속도는 메모리 대역폭이 결정하는데, 전력 제한을 걸어도 메모리 클럭은 그대로라서 손실이 거의 없습니다.

### 전력 제한을 부팅 시 자동 적용 (한 번만 설정)

```bash
sudo tee /etc/systemd/system/nvidia-powerlimit.service > /dev/null <<'EOF'
[Unit]
Description=Set NVIDIA GPU power limit
After=nvidia-persistenced.service

[Service]
Type=oneshot
ExecStart=/usr/bin/nvidia-smi -pl 280

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now nvidia-powerlimit.service
```

## 2-4. 상태 확인 명령 모음 (외우면 좋은 것)

```bash
nvidia-smi                          # GPU 전체 상태 (온도/전력/메모리)
watch -n 1 nvidia-smi               # 1초마다 갱신해서 보기
nvidia-smi topo -m                  # GPU끼리 어떻게 연결됐는지 (NVLink 확인)
nvidia-smi --query-gpu=index,name,pcie.link.gen.current,pcie.link.width.current --format=csv
                                    # 각 GPU의 PCIe 세대/폭 확인 (x1 문제 진단)
nvidia-smi -q -d TEMPERATURE        # 온도 상세
```

## 2-5. 저장 공간 준비

모델 파일은 매우 큽니다 (하나에 60~150GB). 2TB M.2에 폴더를 만들어 둡니다:

```bash
sudo mkdir -p /models
sudo chown $USER:$USER /models
```

모델 내려받기 도구 설치:

```bash
sudo apt install -y python3-pip git
pip install -U "huggingface_hub[cli]"
# 사용 예: hf download Qwen/Qwen3-235B-A22B-Instruct-2507 --local-dir /models/qwen3-235b
```
