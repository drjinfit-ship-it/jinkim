# 6단계. 자동화 운영 — 부팅하면 알아서 켜지고, 주소 하나로 쓰기

> 목표: 전원 버튼만 누르면 모든 모델이 자동으로 뜨고,
> 워치·글래스·폰·맥미니 어디서든 **주소 하나**로 접속되는 상태.

## 6-1. systemd로 자동 시작 등록

모델 서버마다 서비스 파일 하나씩 만듭니다. 예: A컴퓨터의 vLLM 두뇌 모델.

```bash
sudo tee /etc/systemd/system/llm-brain.service > /dev/null <<'EOF'
[Unit]
Description=vLLM main brain (8x3090)
After=network-online.target nvidia-persistenced.service

[Service]
User=jin
Environment="CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7"
ExecStart=/home/jin/vllm-env/bin/vllm serve QuantTrio/Qwen3-235B-A22B-Instruct-2507-AWQ \
  --tensor-parallel-size 8 --gpu-memory-utilization 0.92 \
  --max-model-len 32768 --host 0.0.0.0 --port 8000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now llm-brain.service
journalctl -u llm-brain -f        # 로그 보기
```

B컴퓨터에는 같은 방식으로:
- `llm-docs.service`: `CUDA_VISIBLE_DEVICES=0,1,2,3` → Solar-Open-100B (포트 8001)
- `llm-whisper.service`: `CUDA_VISIBLE_DEVICES=7` (2080Ti) → faster-whisper 서버 (포트 8002)
- `llm-embed.service`: `CUDA_VISIBLE_DEVICES=8` (2080Ti) → 임베딩/리랭커 (포트 8003)

> 핵심 기술: `CUDA_VISIBLE_DEVICES`로 서비스마다 GPU를 나눠주는 것.
> 이렇게 하면 한 컴퓨터에서 여러 모델이 서로 방해 없이 동시에 돕니다.

## 6-2. LiteLLM — 주소 하나로 전부 묶기

어느 기기든 `http://관문주소:4000` 하나만 알면 되게 만듭니다.

```bash
pip install 'litellm[proxy]'
```

`~/litellm-config.yaml`:

```yaml
model_list:
  - model_name: brain                # 두뇌 (A컴퓨터)
    litellm_params:
      model: openai/qwen3-235b
      api_base: http://192.168.100.1:8000/v1
      api_key: none
  - model_name: docs                 # 문서 담당 (B컴퓨터)
    litellm_params:
      model: openai/solar-open-100b
      api_base: http://192.168.100.2:8001/v1
      api_key: none
  - model_name: embeddings           # RAG 임베딩 (B컴퓨터 2080Ti)
    litellm_params:
      model: openai/qwen3-embedding-8b
      api_base: http://192.168.100.2:8003/v1
      api_key: none
```

```bash
litellm --config ~/litellm-config.yaml --port 4000
```

이제 Claude Code든 자작 에이전트든 앱이든, OpenAI 호환 API로 `http://서버:4000/v1`에 모델 이름(brain/docs/embeddings)만 바꿔 부르면 됩니다. 같은 이름의 모델을 두 대에 중복 등록하면 자동 부하 분산도 됩니다.

## 6-3. Open WebUI — 채팅 화면

폰·태블릿·맥미니 브라우저에서 쓰는 ChatGPT 같은 화면:

```bash
docker run -d --name open-webui -p 3000:8080 \
  -v open-webui:/app/backend/data \
  -e OPENAI_API_BASE_URL=http://192.168.100.1:4000/v1 \
  --restart always ghcr.io/open-webui/open-webui:main
```

→ 브라우저에서 `http://서버IP:3000` 접속. 갤럭시 폰 홈화면에 바로가기를 추가하면 앱처럼 씁니다.

## 6-4. 음성 파이프라인 (워치/Rokid → 텍스트 → LLM)

B컴퓨터 2080Ti에 Whisper 서버를 올립니다:

```bash
pip install faster-whisper
# OpenAI 호환 STT 서버 예시 (speaches 프로젝트 - 구 faster-whisper-server)
docker run -d --name whisper --gpus '"device=7"' -p 8002:8000 \
  --restart always ghcr.io/speaches-ai/speaches:latest-cuda
```

흐름: 워치/글래스 녹음 → (폰 경유 업로드) → `http://서버:8002/v1/audio/transcriptions` → 텍스트 → LiteLLM의 brain 모델로 요약/분류 → RAG 저장.

한국어 정확도를 더 올리려면 한국어 파인튜닝 모델(ghost613/whisper-large-v3-turbo-korean)로 교체하세요.

## 6-5. 모델 교체를 편하게: llama-swap (선택)

llama.cpp 계열 모델을 여러 개 등록해 두고, 요청이 올 때만 자동으로 켜고 끄는 도구입니다. VRAM이 부족한데 모델을 여러 개 번갈아 쓰고 싶을 때 유용합니다. (https://github.com/mostlygeek/llama-swap)

## 6-6. 모니터링

```bash
# 간단히
watch -n 1 nvidia-smi
# 예쁘게 (터미널 대시보드)
pip install nvitop && nvitop
```

- 본격 대시보드: Prometheus + Grafana + dcgm-exporter (GPU 온도/전력/사용률 그래프)
- B컴퓨터는 IPMI 웹에서 전력·팬·온도를 GPU와 무관하게 볼 수 있습니다.

## 6-7. 안전 수칙

1. **공유기 포트포워딩으로 이 서버들을 인터넷에 직접 열지 마세요.** vLLM/llama.cpp/RPC 서버는 인증이 없거나 약합니다. 외부에서 쓰려면 Tailscale(무료 VPN)을 양쪽에 설치하는 것이 가장 쉽고 안전합니다.
2. LiteLLM에 `master_key`를 설정해 API 키 인증을 켜세요.
3. 정기적으로 `nvidia-smi -q -d TEMPERATURE`로 VRAM 온도를 확인하세요 (95°C 넘으면 서멀패드 점검).
