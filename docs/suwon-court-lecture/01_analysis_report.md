## 2. 강점 분석

**결론: 이 강의의 강점은 "실패 선경험 → 규칙 3개 → 즉시 성공"이라는 자기효능감 설계와, 청중이 자기 몸에서 증거를 얻는 A/B 비교 구조, 그리고 법원 직군의 언어(피해자·범인·유죄·벌금)로 통증 원리를 번역한 데 있다.**

### 2-1. 강의 전체를 관통하는 와우 구조

```

   ↓
```
